=================
check_lft_balance
=================

--------------------------------------------------
check InfiniBand unicast forwarding tables balance
--------------------------------------------------

:Date: 2017-08-21
:Manual section: 8
:Manual group: Open IB Diagnostics

SYNOPSIS
========

check_lft_balance -l <lft-output> -i <ibnetdiscover-cache> [-e] [-v]


DESCRIPTION
===========

check_lft_balance is a script which checks for balancing in Infiniband
unicast forwarding tables.  It analyzes the output of
**dump_lfts(8)** and an **ibnetdiscover** cache file

On non-Debian distributions, the script is installed as
**check_lft_balance.pl**.

OPTIONS
=======

**-h**
        show help

**-l <lft-output>**
        file containing the output of **dump_lfts(8)** (required)

**-i <ibnetdiscover-cache>**
        file containing the cache generated by **ibnetdiscover --cache**
        (required)

**-e**
        turn on heuristic(s) to look at switch balances deeper

**-v**
        verbose output, output all switches
